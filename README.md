# Помощник путешественника на MCP Туту

ИИ-агент подбирает билеты и отели, разговаривая с пользователем обычным языком.
Данные — живые, из MCP-сервера Туту (`https://mcp.tutu.ru/mcp`), без моков.

## Как это работает

```
пользователь → чат → агент (OpenRouter) → инструменты MCP Туту → карточки на экране
                              ↓
                    Postgres: история диалогов + кэш ответов
```

Агент сам решает, какой инструмент вызвать: поиск авиабилетов, поездов, автобусов,
электричек, отелей или сравнение видов транспорта. Перед первой работой с доменом
он читает плейбук Туту (`get_*_instructions`), чтобы не ошибиться в параметрах.

### Главное архитектурное решение

Ответы MCP весят ~26 КБ на запрос. Если отдавать их модели целиком, диалог становится
медленным и дорогим, а модель начинает пересказывать поля текстом вместо интерфейса.

Поэтому инструменты обёрнуты (`lib/mcp.ts`):

- **полный JSON уходит в UI** и рисуется карточками рейсов и отелей;
- **в модель через `toModelOutput` уходит выжимка** — 5 вариантов с ценой, временем и пересадками.

Замер на реальном поиске Москва → Санкт-Петербург:

| | размер |
| --- | --- |
| полный ответ Туту (в UI) | 26 305 символов |
| выжимка (в модель) | 1 971 символ |
| экономия контекста | **93 %** |

Повторный запрос берётся из кэша в Postgres: 2430 мс → 5 мс. Это же защищает
от HTTP 429 при отладке и на демо.

## Запуск

```bash
npm install
cp .env.example .env          # вписать OPENROUTER_API_KEY
npm run db:up                 # Postgres в Docker
npm run migrate               # схема базы
npm run dev                   # http://localhost:3100
```

Проверить, что живые данные идут (без языковой модели):

```bash
npm run smoke
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | приложение на http://localhost:3100 |
| `npm run db:up` / `db:down` | Postgres в Docker |
| `npm run migrate` | миграции Prisma |
| `npm run studio` | Prisma Studio |
| `npm run smoke` | проверка связки MCP → кэш → выжимка |
| `npm run mcp:probe [tool]` | сырой ответ инструмента MCP |
| `npm run lint` | ESLint |

## Структура

```
app/api/chat/route.ts    агентный цикл: streamText + инструменты MCP
app/page.tsx             новый диалог
app/c/[id]/page.tsx      сохранённый диалог
lib/mcp.ts               подключение к Туту, кэш, обёртка инструментов
lib/tutu-types.ts        типы ответов Туту и разбор списков (нужны и клиенту)
lib/prompt.ts            системный промпт агента
lib/config.ts            константы: модель, лимиты, TTL кэша
lib/chat-store.ts        сохранение и загрузка диалогов
components/chat/         чат и рендер вызовов инструментов
components/cards/        карточки транспорта и отелей
prisma/schema.prisma     ChatSession, Message, McpCache
```

## Стек

Next.js 16 (App Router) · TypeScript · AI SDK 7 · `@ai-sdk/mcp` · OpenRouter ·
Prisma 7 + Postgres 18 · Tailwind 4 + shadcn/ui

Модель задаётся одной строкой в `lib/config.ts` — основная и запасная у разных
провайдеров, чтобы сбой одного не останавливал демо.
