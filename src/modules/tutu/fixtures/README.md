Нужны по двум причинам:

1. Разработка и отладка без обращений к боевому серверу — у него есть rate limit,
   и при интенсивных запросах он блокирует по IP (проверено на себе).
2. Прогрев кэша перед демо: сценарий должен воспроизводиться, даже если сервер
   недоступен. В интерфейсе такие данные помечаются временем снятия.
