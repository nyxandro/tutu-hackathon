# Города России

Справочник для подсказок при вводе. 1134 города с регионом и населением.

Источник: [pensnarik/russian-cities](https://github.com/pensnarik/russian-cities),
открытые данные. Оставлены только поля, нужные подсказкам: `n` — название,
`r` — регион, `p` — население (для ранжирования, крупные города выше).

Нужен потому, что у MCP Туту нет автодополнения городов: ресурс `tutu://geo`
содержит всего два города и помечен как демонстрационный снимок.
